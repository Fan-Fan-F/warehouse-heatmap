# warehouse-heatmap · 仓库库位热力图与拣货路径模拟

零依赖（原生 HTML/CSS/JS + Canvas）的仓储可视化工具：用热力图呈现库位的拣选热度，并对同一张订单对比两种经典拣货路径策略的行走距离。

## 功能

- **ABC 分类布局**：A 类爆品（日拣 15+）自动占据靠近出入口的黄金位，B 类常规、C 类长尾散布深处——符合真实仓库的货位规划原则
- **库位热力图**：颜色 × 透明度双重编码 SKU 日拣选频次，一眼识别热区
- **订单拣选模拟**：按 SKU 热度加权抽样生成 8 件拣货清单（爆品被抽中的概率更高）
- **双策略路径对比**：
  - **贪心最近邻**：每次走向距离最近的下一个库位
  - **S 形穿越**：按巷道蛇形遍历，行业标准做法，密集拣选时更稳
- **行走距离统计**：实时显示两种策略的总格数与节省百分比

## 仓库模型

```
8 排 × 14 巷道 = 112 个库位，出入口位于左下角
行走距离 = 曼哈顿距离（巷道行走近似）
路径终点 = 返回出入口复核打包
```

## 路径策略对比结论

| 场景 | 更优策略 |
| --- | --- |
| 订单分散、每巷道 1-2 件 | 贪心最近邻（少穿巷道） |
| 订单密集、单巷道多件 | S 形穿越（避免来回折返） |
| 真实 WMS | 中位点/最大间隙启发式 + 波次合并 |

## 本地运行

直接用浏览器打开 `index.html` 即可。点击「生成订单」多次可观察不同订单结构下两种策略的胜负互换。
